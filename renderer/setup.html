WeighCore Terminal Setup

First-run configuration for this weighbridge PC

Configure this station once. Pick which weighbridge this PC is, point it at the indicator, cameras and central server, then Finish — the terminal remembers it from now on.

1 Station identity

The Scale ID is what tags every ticket so the central/ERP knows which bridge it came from. Choose a different one on each PC.

2 Weight indicator

Serial COM port the weighbridge indicator streams on. Use “Test weight” to confirm a live reading.

not tested

3 Cameras

One row per lane camera (RTSP). “Test” grabs a single frame. Leave blank if a lane has no camera.

4 Central server

The shared SQL server both bridges push to (reached over an SSH tunnel). “Test connection” verifies it end-to-end.

not tested
